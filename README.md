# ZapSMTP OpenAPI

The OpenAPI 3.1 description of the ZapSMTP API, with request and response schemas: [`openapi.json`](openapi.json).

Use it to generate a client in a language without an official SDK, to import the API into Postman or Insomnia, or to validate requests in tests. The same file is served at https://zapsmtp.com/openapi.json.

Official SDKs: Node.js, Python, Go, PHP, Laravel, Ruby, Java and .NET. See https://zapsmtp.com/docs/sdks/.
